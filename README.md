# Tower Defence

A Unity 2D tower-defense game ported from the original Python/Pygame project.

## Requirements

- Unity 6.2 (`6000.2.6f2`)

## Open and run

1. In Unity Hub, choose **Add > Add project from disk**.
2. Select this project folder.
3. Open `Assets/Scenes/SampleScene.unity`.
4. Press **Play**.

## Gameplay

- Click an empty tower spot and choose Archer, Cannon, or Magician.
- Select a tower to see its range and access its upgrade or sell options.
- Use the play/next-wave button to control waves and the speed button to toggle game speed.
